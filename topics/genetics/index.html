分离与独立

分離の法則・独立の法則

Aa×Aa → AA:Aa:aa=1:2:1，表型 3:1。两对独立基因 AaBb 自交 → 9:3:3:1。测交（検定交雑）：与隐性纯合子 aa 交配，后代比例直接反映配子比例。

例外情况

不完全優性など

不完全显性（不完全優性，紫茉莉 赤×白→粉）F2 为 1:2:1。致死基因（致死遺伝子）：黄色鼠 Yy×Yy → 2:1。复等位基因：ABO 血型 IA、IB 共显性，i 隐性。

伴性遗传

伴性遺伝

X 染色体上的隐性基因（如红绿色盲）：男性 XaY 即表现。携带者母亲 × 正常父亲 → 儿子 1/2 患病、女儿全正常。

连锁与交换

連鎖と組換え

$$\text{組換え価}(\%)=\dfrac{\text{組換え型}}{\text{全体}}\times100$$

AB/ab 测交，组换价 r：AB:Ab:aB:ab = (1−r):r:r:(1−r)（各除以 2）。组换价越大，基因距离越远（染色体地図）。

变形分离比

分離比の変形

基因相互作用F₂ 比
互补基因9 : 7
抑制基因13 : 3
隐性上位（条件基因）9 : 3 : 4
累加/重复基因15 : 1
$$\text{重组率}=\frac{\text{重组型个体数}}{\text{总个体数}}\times100\%$$

快速解题技巧

速解テクニック

  • 分枝法：每对基因分开算再相乘 — 两对以上独立遗传的基因，求某基因型・表型的比例或概率。
  • 9:3:3:1 变形比一眼识别 — F₂ 比是 9:7、9:3:4、12:3:1、15:1、13:3、9:6:1 等，总和为 16。
  • 显性个体中的纯合子 = 1/3 — “F₁（或 F₂）显性表型中纯合子占多少”“从显性个体中随机选一个与…杂交”。
  • 重组率：测交看少数类 — 测交比 $a:b:b:a$（两端大、中间小）或求连锁配子比。
  • 伴性遗传：只看母亲的 X — 色盲、血友病，问儿子或女儿的概率。

解答

问 1原创 · EJU 风格

Aa 自交，F₁ 中显性表型个体里纯合子所占比例是？

  1. ① 1/4
  2. ② 1/3
  3. ③ 1/2
  4. ④ 2/3
解答

正解：②

AA:Aa=1:2 → 1/3。

问 2原创 · EJU 风格

AaBb（独立）自交，aabb 的比例是？

  1. ① 1/4
  2. ② 1/8
  3. ③ 1/16
  4. ④ 3/16
解答

正解：③

1/4×1/4=1/16。

问 3原创 · EJU 风格

AaBbCc（独立）自交，三对都表现显性的比例是？

  1. ① 9/64
  2. ② 27/64
  3. ③ 3/4
  4. ④ 1/64
解答

正解：②

(3/4)³=27/64。

问 4原创 · EJU 风格

黄色小鼠 Yy×Yy（YY 致死），子代黄色:灰色 = ?

  1. ① 3:1
  2. ② 2:1
  3. ③ 1:1
  4. ④ 1:2
解答

正解：②

YY 死，Yy:yy=2:1。

问 5原创 · EJU 风格

A 型（IAi）与 B 型（IBi）父母，孩子是 O 型的概率是？

  1. ① 0
  2. ② 1/4
  3. ③ 1/2
  4. ④ 3/4

1/2×1/2=1/4。

问 6原创 · EJU 风格

红绿色盲携带者女性与正常男性结婚，儿子患色盲的概率是？

  2. ② 1/4
  3. ③ 1/2

问 7原创 · EJU 风格

AaBb 测交得 AaBb:Aabb:aaBb:aabb=4:1:1:4，组换价是？

  1. ① 10%
  2. ② 20%
  3. ③ 25%
  4. ④ 40%
解答

正解：②

(1+1)/10=20%。

问 8原创 · EJU 风格

A–B 组换价 8%，B–C 12%，A–C 20%，三基因的排列顺序是？

  1. ① A-B-C
  2. ② B-A-C
  3. ③ A-C-B
  4. ④ 无法判断
解答

正解：①

8+12=20，B 在中间。

问 9原创 · EJU 风格

AB/ab（组换价 20%）个体产生 Ab 配子的比例是？

  2. ② 10%
  3. ③ 20%
  4. ④ 40%
解答

正解：②

重组配子 Ab、aB 各 10%。

问 10原创 · 过去问高频题型

AaBb 测交得 AB:Ab:aB:ab $=42:8:8:42$。A–B 间重组率是？

问 11原创 · 过去问高频题型

两种白花品种杂交 F₁ 全为紫花，F₂ 紫:白 = 9:7。F₂ 白花中纯合子占？

  1. ① $\frac17$
  2. ② $\frac37$
  3. ③ $\frac27$
  4. ④ $\frac47$
解答

正解：②

白花 7 份中纯合子 AAbb、aaBB、aabb 共 3 份：3/7。

问 12原创 · 过去问高频题型

  4. ④ $\frac34$
解答

正解：②

$\frac12\times\frac12=\frac14$。

问 13原创 · 过去问高频题型

只产生 AB、ab 两种配子：A_B_ : aabb = 3:1。
