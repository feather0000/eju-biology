生殖方式

生殖

无性生殖（無性生殖：分裂・出芽・营养繁殖）子代与亲代遗传相同（クローン）；有性生殖（有性生殖）通过配子（配偶子）结合产生遗传多样性。

卵裂与胚的发育

卵割と胚発生

卵割（卵割）是细胞不生长的快速分裂，n 次卵割后 2ⁿ 个细胞。海胆为等黄卵（等黄卵），蛙为端黄卵（端黄卵，植物极卵黄多、卵裂慢）。顺序：桑椹胚→囊胚（胞胚）→原肠胚（原腸胚）→神经胚（神経胚）。

三胚层

三胚葉

胚层分化
外胚层 外胚葉表皮、神经系统（脳・脊髄）、眼的晶状体
中胚层 中胚葉脊索、肌肉、骨骼、心脏・血管、肾脏
内胚层 内胚葉消化管上皮、肝脏、胰脏、肺

诱导

誘導

シュペーマン的移植实验：原口背唇部（形成体 オーガナイザー）诱导外胚层形成神经管。眼的形成：眼杯诱导表皮形成晶状体（水晶体），晶状体再诱导角膜（誘導の連鎖）。

分化　细胞分化是基因的选择性表达；iPS 细胞由体细胞导入少数基因重新获得多能性（山中伸弥）。

花器官的 ABC 模型与同源异形基因

ABCモデル

A 单独 → 花萼，A+B → 花瓣，B+C → 雄蕊，C 单独 → 雌蕊。A 与 C 互相抑制。B 缺失：萼–萼–雌蕊–雌蕊。

被子植物的双受精

重複受精

花粉管中 2 个精细胞：一个与卵细胞 (n) 结合成受精卵 (2n)，另一个与 2 个极核结合成胚乳核 (3n)。

例题

例題

例题 1　卵割细胞数

受精卵进行 5 次卵割后有几个细胞？

解答

2⁵=32。

问 7原创 · EJU 风格

胚发育的正确顺序是？

  1. ① 囊胚→桑椹胚→原肠胚
  2. ② 桑椹胚→囊胚→原肠胚→神经胚
  3. ③ 原肠胚→囊胚→神经胚
  4. ④ 神经胚→原肠胚→囊胚
解答

问 8原创 · 过去问高频题型

被子植物胚乳细胞的核相是？

  1. ① n
  2. ② 2n
  3. ③ 3n
  4. ④ 4n
解答

正解：③

精核 n + 两个极核 2n = 3n。

问 9原创 · 过去问高频题型

B 类基因功能缺失的拟南芥，花从外到内为？

  1. ① 萼、萼、雌蕊、雌蕊
  2. ② 瓣、瓣、雄蕊、雄蕊

问 10原创 · 过去问高频题型
